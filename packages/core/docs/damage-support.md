# ダメージ計算の対応状況

coreの`calculateDamage`が扱う仕様のメモです。ここにない仕様は、実装前に入力型と`DamageResult`への影響を確認します。

## 対応済み

- 基本ダメージ計算
- 乱数補正
- タイプ一致補正
- タイプ相性補正
- 急所補正
- 能力ランク補正
- 性格補正込みの実数値計算
- シングル、ダブルの範囲補正
- 天候によるダメージ補正
- 天候による防御、特防補正
- 道具による攻撃、特攻、防御、特防の能力値補正
- 道具による条件付き与ダメージ補正
- やけどによる物理ダメージ補正
- リフレクター、ひかりのかべ、オーロラベールによるダメージ補正
- エレキ、グラス、サイコフィールドによる威力補正
- ミストフィールドによるドラゴン技のダメージ補正
- グラスフィールドによる特定技のダメージ補正とターン終了時回復
- タイプ、特性、道具、ねをはるによる接地判定
- うちおとすなどを表す接地状態の明示的な上書き
- ねをはるによるターン終了時回復
- ターン終了時回復
- 攻撃後回復
- ターン終了時の定数HPダメージ
- もうどくのカウンター付き定数HPダメージ
- 1回だけ発動するダメージ軽減効果
- 半減実による条件付きダメージ軽減と1回限りの消費
- ホズのみのノーマル技に対する例外的なダメージ軽減
- 連続技のhit数指定
- スキルリンクによる連続技最大hit化
- おやこあいの追加hit

## 近似対応

- 連続技は、同じ乱数枠を各hitに使う前提で扱う
- おやこあいの追加hitは、単体かつ元が単発の攻撃技だけに適用する
- 回復や定数HPダメージは、KO確率用のHP推移に含める
- しんかのきせきは、所持しているポケモンを進化前として扱い、常に防御、特防補正を適用する

# ダメージ計算の対応状況

coreの`calculateDamage`が扱う仕様のメモです。ここにない仕様は、実装前に入力型と`DamageResult`への影響を確認します。

## 対応済み

- 基本ダメージ計算
- 乱数補正
- タイプ一致補正
- タイプ相性補正
- 急所補正
- 能力ランク補正
- 性格補正込みの実数値計算
- シングル、ダブルの範囲補正
- 天候によるダメージ補正
- 天候による防御、特防補正
- ターン終了時回復
- 攻撃後回復
- ターン終了時の定数HPダメージ
- もうどくのカウンター付き定数HPダメージ
- 1回だけ発動するダメージ軽減効果
- 連続技のhit数指定
- スキルリンクによる連続技最大hit化
- おやこあいの追加hit

## 近似対応

- 連続技は、同じ乱数枠を各hitに使う前提で扱う
- おやこあいの追加hitは、単体かつ元が単発の攻撃技だけに適用する
- 回復や定数HPダメージは、KO確率用のHP推移に含める

## 未対応

- フィールド補正
- まもる系補正
- やけどによる物理ダメージ補正
- てんねん
- かたやぶり
- テラスタル、ステラ補正
- 威力変動技
- タイプ変動技
- 固定ダメージ技
- 攻撃、防御に使う能力が特殊な技
- 複数ポケモンへのHP引き継ぎ計算
- 逆算系の調整計算
